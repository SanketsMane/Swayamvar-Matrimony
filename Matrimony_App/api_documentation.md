# Matrimony App API Documentation

This document provides a comprehensive guide to the APIs for the **Matrimony App** (Member and User flows), including authentication, profile management, partner search, and interactions.

**Base URL:** `https://swayamvarmatrimony.in/api/v1`

**Authentication:** 
Most APIs require a Bearer Token for authentication.
- Header: `Authorization: Bearer {token}`

---

## 1. Authentication & Registration

### Sign Up (New Member)
- **Endpoint:** `POST /signup`
- **Use Case:** Register a new member on the matrimony platform.
- **Parameters:** `first_name`, `last_name`, `email` (optional), `phone`, `password`, `gender`, `date_of_birth`, `on_behalf`.

### Sign In
- **Endpoint:** `POST /signin`
- **Use Case:** Access the matrimony member dashboard.
- **Parameters:** `email_or_phone`, `password`.

### OTP Verification
- **Endpoints:**
    - `POST /otp/send`: Send verification code to phone/email.
    - `POST /otp/verify`: Verify the received code.

### Forgot/Reset Password
- **Endpoints:**
    - `POST /forgot/password`: Request a reset code.
    - `POST /reset/password`: Set a new password with a valid code.

## 2. Member Profile Management

### My Dashboard
- **Endpoint:** `GET /member/dashboard`
- **Use Case:** Overview of profile status, package details, and matching suggestions.

### Profile Wizard (Unified Update)
- **Endpoint:** `POST /member/profile-wizard/update`
- **Use Case:** Update multiple profile sections in one go.

### Specific Section Updates
- **Endpoints:**
    - `POST /member/basic-info/update`: Name, Gender, DOB, On Behalf.
    - `POST /member/address/update`: Present and Permanent Address.
    - `POST /member/physical-attributes/update`: Height, Weight, Blood Group, etc.
    - `POST /member/spiritual-background/update`: Religion, Caste, Manglik status.
    - `POST /member/career-status/update`: Occupation, Income.

### Profile Images
- **Endpoints:**
    - `POST /member/profile-picture/update`: Update main profile photo.
    - `POST /member/gallery-image`: Add/Delete images in the gallery.

## 3. Partner Search & Discovery

### Member Listing (Advanced Search)
- **Endpoint:** `POST /member/member-listing`
- **Use Case:** Filter partners by Age, Religion, Location, Profession, etc.
- **Key Filters:** `age_from`, `age_to`, `religion_id`, `caste_id`, `state_id`, `city_id`, `manglik`.

### Public Profile View
- **Endpoint:** `GET /member/public-profile/{id}`
- **Use Case:** View detailed profile of another member.

### Matched Profiles
- **Endpoint:** `GET /member/matched-profile`
- **Use Case:** Automated partner suggestions based on preferences.

## 4. Interactions & Social

### Express Interest
- **Endpoints:**
    - `POST /member/express-interest`: Send interest to a profile.
    - `GET /member/my-interests`: View interests sent and received.
    - `POST /member/interest-accept`: Accept a received interest.

### Shortlisting
- **Endpoint:** `POST /member/add-to-shortlist`
- **Use Case:** Save a profile for later viewing.

### Messaging (Chat)
- **Endpoints:**
    - `GET /member/chat-list`: List of conversations.
    - `GET /member/chat-view/{id}`: Detailed chat history.
    - `POST /member/chat-reply`: Send a new message.
